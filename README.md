How to Navigate This Project

If you are a Business Stakeholder: Start with the Business Presentation and the Business Infographic to understand the "why" and the resulting impact of the project without getting bogged down in code.

If you are a Technical Reviewer: Begin with the Technical Presentation and Technical Infographic to grasp the methodology, then dive into the AIM Capstone Notebook.ipynb to review the actual implementation and code.
